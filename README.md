# Video‑play
> 纯前端浏览器 ASCII 视频转换器，**全部运算在本地浏览器完成，不上传视频到服务器**。将视频转成字符画 ASCII 动画，支持彩色、音频、导出 TXT / HTML 动画 / WebM 录制。复古 Windows98 UI 风格单文件 HTML 工具。

## 功能概览
- 🎞️ 本地视频解析：支持 mp4 / webm / mov / m4v / ogv，文件选择或拖拽上传
- 🎨 ASCII 渲染
  - 4套字符集：经典 10 级、细腻 16 级、方块块字符、二值黑白
  - 彩色模式 / 反相
  - 亮度、对比度调节
  - 可调节输出列数（画面宽度）自动计算行数
- 🔊 音频支持：原声播放，音量调节，导出 HTML 动画可嵌入 wav 音频
- ▶️ 播放器：播放 / 暂停、进度条、时间轴、拖拽跳转
- 💾 导出能力
  1. 当前帧导出为纯文本 `.txt`
  2. 当前帧导出静态 `.html`（彩色字符画面）
  3. 导出**完整 ASCII 动画 HTML 文件**（内置播放器、进度条、可带音频，最大240帧）
  4. 录制输出 WebM 视频文件（MediaRecorder，可选带音频）
  5. 一键复制当前帧 ASCII 文本到剪贴板
- 📱 响应式布局：手机/PC自适应，移动端自动切换上下布局
- 🖼️ UI：复古 Windows 9x 灰色3D凸起窗口样式

## 技术栈
- 原生 HTML + CSS（无任何第三方依赖）
- JavaScript API
  - `<video>`：视频解码
  - `canvas`：视频帧采样、像素读取
  - `AudioContext`：音频播放、提取音频流
  - `MediaRecorder`：录制画布输出 WebM
  - File API / Blob / download：本地导出下载
- 全部逻辑运行浏览器客户端，**不需要后端服务**

## 参数说明
| 参数 | 说明 |
|---|---|
| 列数 | ASCII画面横向字符数量，范围30‑200，越大画面越精细，性能消耗越高 |
| 字符集 | 灰度映射字符，不同纹理效果 |
| 色彩 | 勾选开启彩色字符；关闭输出纯黑白文本 |
| 反相 | 翻转明暗，黑变白白变黑 |
| 声音 | 开启/关闭视频原声；导出动画HTML也会携带音频 |
| 音量 | 0‑100，控制播放音量 |
| 亮度 | -60 ~ +60，调整画面亮度 |
| 对比 | 50‑220，画面对比度 |

> 导出动画HTML限制：固定15FPS，最多截取**240帧**；如果原视频更长，只会截取前一段，状态提示会给出提醒。音频编码为wav base64嵌入HTML，音频过大时会自动舍弃音轨。

## 使用方法
1. 将下方完整源码保存为 `ascii‑video‑converter.html`
2. 使用现代浏览器直接打开本地HTML文件（不需要web服务器，双击即可）
3. 两种导入视频：
   - 点击【选择文件】选取本地视频
   - 将视频文件拖拽到右侧输出窗口
4. 调整输出参数：列数、字符集、色彩、亮度对比度
5. 点击【▶播放】，浏览器实时渲染ASCII字符视频
6. 使用导出按钮保存结果：
   - 单帧：存TXT / 存HTML / 复制
   - 完整动画：导出动画HTML（自包含播放器，可以发给别人直接打开）
   - 录制WebM：开始录制后视频从头播放，完成点停止录制，浏览器下载webm视频

> ⚠️ 浏览器限制提示
> 1. Safari部分视频编码兼容性差，优先使用H.264编码MP4
> 2. WebM录制依赖浏览器`MediaRecorder`API，部分移动端浏览器不支持；此时请改用导出动画HTML
> 3. 音频播放：浏览器策略要求必须点击页面后音频才能播放；第一次播放可能需要二次点击
> 4. 导出HTML嵌入base64音频会增大文件体积，长视频会自动丢弃音频轨道
